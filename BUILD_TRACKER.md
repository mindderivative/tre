# Build Tracker — moved

From `0.5.0`, Tesserae Engine's plan and progress are tracked in the GitHub
project **[Tesserae Rendering Engine](https://github.com/users/mindderivative/projects/3)** (decided 2026-09-30). Each
release is a repo milestone; each of its milestones is an issue with its steps
as a checklist, and each step lands with a comment recording what changed. The
project's README describes the conventions.

- `0.5.0` — custom windowing ([#28](https://github.com/mindderivative/tre/issues/28)):
  M1 is [#31](https://github.com/mindderivative/tre/issues/31) (done), M2–M6 are
  [#32](https://github.com/mindderivative/tre/issues/32)–[#36](https://github.com/mindderivative/tre/issues/36).
  This file's last full version, with M1's record, is commit `2b37456`.
